### 🚀 機能改善

* **[アプリケーション監督]** 「環境」と「プロキシ環境」のドロップダウン項目を名前の昇順で表示するように改善。名前に含まれる数字は数値順で並べ替えられ、たとえば `cluster-2` は `cluster-10` より前に表示される。

### 🐛 不具合修正

* **[ai]** MCP ツールのグローバル権限設定がアプリケーションの再起動後に失われる問題と、アプリケーションインスタンス間で設定が一致しない問題を修正。 ([#11476](https://github.com/nocobase/nocobase/pull/11476))
* **[UI テンプレート]** 別のポップアップを開くアクションからテンプレートを保存した後、テンプレートの参照方式をコピーに変更しても、元のポップアップへの変更が引き続き同期される問題を修正。 ([#11491](https://github.com/nocobase/nocobase/pull/11491))
* **[AI 従業員]** Web UI または API 経由での stdio MCP サービスの作成、およびデプロイ設定で管理されている接続の変更・削除を禁止。起動・停止と接続テストは引き続き利用可能。MCP のデプロイ設定は `storage/ai/mcp/servers.json` から読み込むように変更し、TS/JS ファイルは自動的に読み込まないように変更。 ([#11461](https://github.com/nocobase/nocobase/pull/11461))
* **[テンプレート印刷]** アップグレード後、必要な依存関係が不足しているためテンプレート印刷プラグインを読み込めない問題を修正。
