### 🐛 不具合修正

* **[client-v2]**
  * 一対多ブロックで、対象テーブルにレコードを一意に識別するフィールドが複数設定されている場合、レコードを削除できない問題を修正。v1 / v2 の一括削除にも対応。 ([#11423](https://github.com/nocobase/nocobase/pull/11423))
  * サイドバーの折りたたみボタンがナビゲーションパネルのリンクに重なり、操作できなくなる問題を修正。 ([#11546](https://github.com/nocobase/nocobase/pull/11546))
* **[UI テンプレート]** UI テンプレートの作成、編集、削除、およびテンプレートの参照レコードの閲覧にテンプレート管理権限が必要になりました。ログインユーザーは引き続きテンプレートを読み取ることができます。 ([#11537](https://github.com/nocobase/nocobase/pull/11537))
* **[ブロック：テンプレート（廃止済み）]** 旧バージョンのブロックテンプレートレイアウトを保存する際、「設定画面を許可」権限が必要になりました。 ([#11538](https://github.com/nocobase/nocobase/pull/11538))
* **[ワークフロー：ループノード]** トップレベルのループ条件を設定する際、ローカル変数を選択できない問題を修正。 ([#11583](https://github.com/nocobase/nocobase/pull/11583))
* **[バックアップマネージャー]** より新しいメジャーバージョンの `pg_dump` で作成された PostgreSQL バックアップを、古いバージョンの `pg_restore` で復元しようとした場合、データベースを変更する前に復元処理を中止するように修正。 ([#11585](https://github.com/nocobase/nocobase/pull/11585))
* **[データソース：メインデータベース]** メインデータベースから読み込んだテーブルでフィールドを同期できない問題を修正。また、物理テーブル名に設定プレフィックスが付いている場合も、既存フィールドのメタデータを保持するように修正。 ([#11327](https://github.com/nocobase/nocobase/pull/11327))
* **[ワークフロー]** V1 ワークフローエディターで、ループ内の Webhook レスポンスなどのノードを設定するとエラーが発生する問題を修正。 ([#11581](https://github.com/nocobase/nocobase/pull/11581))
* **[公開フォーム]** 公開フォームは、設定されたデータソースとデータテーブルへのデータ送信のみを受け付けるように変更。 ([#11536](https://github.com/nocobase/nocobase/pull/11536))
* **[マルチスペース]** 現在のスペース内のレコードから画像やファイルのプレビューを開くと 404 エラーが発生する問題を修正。
* **[マイグレーション管理]** PostgreSQL のマイグレーションで、複数行フィールド内の `--` で始まる行が失われる、改行コードが変更される、またはエクスポートしたデータを復元できない問題を修正。
* **[データソース：外部 Oracle]** Oracle Thin で、設定された Schema に基づいてデータテーブルを一覧表示するように改善。以前選択されていたものの現在は利用できないテーブルを明示し、新たに選択したテーブルが利用できない場合はエラーを表示。
