### **🚀 機能改善**

- **[AIワーカー]** AIワーカーとの会話で多重にラップされた RangeError が発生した場合でも、サーバーログに元のスタックトレースを表示し、問題の原因を特定しやすくしました。 ([#11640](https://github.com/nocobase/nocobase/pull/11640?utm_source=chatgpt.com))

### **🐛 不具合修正**

* **[データソース：REST API]**

  * REST API データソースプラグインで TypeScript 宣言ファイルを生成する際、リリースビルドが失敗する問題を修正しました。
  * REST API データテーブルのフィールドをクリアして再取得した際、保存できなくなる場合がある問題と、既存フィールドの表示名への変更が失われる場合がある問題を修正しました。
* **[データソース：外部 SQL Server]** SQL Server の外部データソースで、dbo スキーマに属するテーブルとビューのみを一覧に表示するようにしました。
